# SIQ small editor

**SIQ small editor** — приложение для перемешивания вопросов в пакетах SIGame. Исходный файл не изменяется — программа создаст новый.

## Способы перемешивания

| Режим | Что произойдёт |
| --- | --- |
| **Перемешать всё** | Вопросы всех обычных раундов смешиваются и распределяются по новым раундам и темам. Старые обычные раунды заменяются. |
| **Перемешать раунд/раунды** | То же самое, но только для отмеченных раундов. Остальные сохраняются. |
| **Перемешать темы** | Вопросы отмеченных тем смешиваются и распределяются по новым темам одного нового раунда. Выбранные старые темы удаляются. Если исходный раунд опустел, он тоже удаляется. |
| **Перемешать одну тему** | Меняется только порядок вопросов внутри одной выбранной темы. |

**Финальные раунды в перемешивании не участвуют.** 

## Настройки новых раундов и тем

- **Количество раундов** — желаемое число. Фактическое количество зависит от числа вопросов и вместимости тем и раундов.
- **Тем в раунде** и **Вопросов в теме** — максимальное количество элементов в каждом новом раунде и теме.
- **Название тем** — общее название создаваемых тем.
- **Сквозная нумерация** добавляет к названиям номера: например, «Сборная тема 1», «Сборная тема 2» и далее, без сброса нумерации в новом раунде.

Все вопросы сохраняются. Если они не делятся поровну, последняя тема или раунд будет неполной.
При необходимости создаются дополнительные темы и раунды.

## Отмена и повторные изменения

Каждое следующее перемешивание применяется к результату предыдущего. После операции выбор раундов и тем сбрасывается — для следующей операции выберите их заново.

Стрелка **назад** отменяет изменение, стрелка **вперёд** возвращает отменённое.

Можно скачать результат на любом шаге и продолжить работу. При загрузке другого пакета история начинается заново.

**Обновление или закрытие страницы сбрасывает открытый пакет и все несохранённые изменения.**
